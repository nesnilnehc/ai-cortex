# Review Roadmap

Read-only review of requirement-and-defect roadmaps against
[roadmap-quality](../../rules/roadmap-quality.md). Checks entry granularity,
priority and readiness, readability, source agreement and traceability.
Checks also cover separate status columns, fixed execution labels, short linked
conditions, source-backed transitions and declared closure criteria.
Selected version/schedule views are checked for scope and timing agreement;
unselected views are not required. Destination claims need evidence.
Linked acceptance criteria and evidence are valid; tasks stay outside the main view.

Output follows [findings-list](../../specs/findings-list.md), with explicit evidence
limitations. See [SKILL.md](SKILL.md) for the procedure and Self-Check.
