# Project overview

The entry index for the project's identity and its criteria for success, under `docs/project-overview/`. The documents are ordered by how each is derived: mission -> vision -> North Star -> strategic goals.

## The derivation chain, in order

| Order | Document | Role | Depends on |
| :---: | :--- | :--- | :--- |
| 1 | [mission](mission.md) | The fundamental purpose — why this exists | — |
| 2 | [vision](vision.md) | The long-term future — what is being created | mission |
| 3 | [north-star](north-star.md) | The core success metric | mission, vision |
| 4 | [strategic-goals](strategic-goals.md) | Outcome-oriented goals | vision, north-star |

Phases and milestones are in [process-management/roadmap](../process-management/roadmap.md).
