# Discover and use AI Cortex through work relationships

## Problem / Need

New adopters cannot determine what to do, how related work fits together, or which
capability to use from a flat skill inventory alone. A picture that implies a
mandatory delivery sequence also misrepresents conditional and iterative work.

This primarily supports [Goal 4: adoption friction is low](../../project-overview/strategic-goals.md#goal-4-adoption-friction-is-low),
consistent with the existing website intake. The mapping is inferred from the
user's explicit adoption objective; it does not reprioritize the backlog.
