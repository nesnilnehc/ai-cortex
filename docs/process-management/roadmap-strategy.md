# Roadmap delivery direction

[Main roadmap](roadmap.md) · Updated: 2026-10-21

## Planning basis

The retained strategic plan has no source-backed requirement or defect arrangement.
The current plan puts core capability and channel readiness ahead of deeper
composition. [Checkpoint definitions](#checkpoint-definitions) need reconciliation
before they can establish readiness or completion.

- A backlog item maps to the existing Now or Next direction before work is pulled.
- A requirement outside the roadmap direction is not worked on by default until
  the roadmap changes. Exclusion never means completion.
- Placement grants no implementation or release approval. Closure evidence and
  current measurements remain in [source work records](backlog.md).

## Checkpoint definitions

The prior main document contained both narrative targets and a repeated appendix.
Neither the strategic goals nor the current source records resolve the differences.
The table retains those definitions without selecting a new threshold. Baselines,
measurement denominators, owners and occurrence evidence remain unverified.

| Checkpoint | Narrative definition retained | Appendix definition retained | Unresolved decision |
| --- | --- | --- | --- |
| M5, core intent coverage | “Full coverage” sufficient for everyday work; success text also says 80% or more of high-frequency intents | >80% of high-frequency everyday intents | Full vs 80%; ≥80% vs >80%; define denominator/reference point |
| M6, ecosystem multi-channel verification | Existing skills verified and running smoothly on at least 2 new platforms | Running smoothly on >2 new platforms | ≥2 vs >2; define verified integration evidence |
| M7, complex orchestration and a closed workflow loop | At least 3 high-value end-to-end scenarios built and verified; reuse correctness in at least 2 different project kinds | >3 chained workflows in production | ≥3 vs >3; built/verified vs in production; preserve separate reuse criterion |

M5/M6 success was described as the condition for core delivery and governance
coverage reaching 80%. This is an existing target, not a measured current value.
M7 concerns semi-automated composition of governance/delivery chains; no milestone
occurrence or release is established by this page. Resolve target conflicts through
a source-backed planning decision and record the material revision before using them.
