Before you start

A few useful answers.

Is AI Cortex an agent or an application?

It is an asset library for agents. It supplies callable skills, structural specs, interaction protocols and quality rules. Your existing agent runs the work.

Do I need to adopt everything?

No. Start with a skill that fits a current task. Orchestrator skills combine smaller capabilities for longer workflows. Project-specific governance needs its own explicit adoption. See the adoption guide.

What gets installed?

The installer links skills into ~/.agents/skills and supported IDE locations. User-scoped rules are synced for detected IDEs. Specs, protocols and project-scoped rules stay in the canonical clone for agents to read when needed. See supported installation behavior.

Can I inspect and adapt the library?

Yes. The project is open source under the MIT license. Read the assets, reuse them across projects and contribute improvements through the repository. Read the contribution guide.
