# Prototype illustrations

[work-stories.png](work-stories.png) was generated on 2026-10-27 using the built-in image generation
tool. The exact generation prompt is retained in [image-prompt.txt](image-prompt.txt).

The asset is an eight-scene contact sheet. The live explainer presents one scene
at a time through CSS positioning: research, planning, design, implementation,
checking, saving a version, delivery and supporting tools. Illustrations explain
concepts and do not claim to be product screenshots or actual execution evidence.

The source was visually inspected before adoption and copied into this directory;
the original generated asset remains in the tool's default output location. The
image was not edited or upscaled. Source labels, buttons and accessible image
explanations are native HTML rather than text baked into the raster.
