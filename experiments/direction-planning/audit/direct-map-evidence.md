# Direct topic relationship verification

Date: 2026-10-27. Local prototype only; no publication or owner acceptance.

## Source and model evidence

62 model tests pass. The changed direct-topology and port contract failed before
its new export and implementation existed. It now verifies ten unique topics,
13 direct edges without a work hub, connected coverage, exact source excerpts,
conditions, relationship basis, feedback/support distinctions, snapshot isolation
and actual topic-port/label geometry.

The topic registry projects artifact consumption, conditional calls, repair loops
and scoped support from inspected canonical contracts. Research recommendations
can inform a decision but do not approve roadmaps or invoke planning. Existing
artifacts can satisfy an input without rerunning their producers. No topic edge
is silently added to the unchanged 53-edge concrete skill registry. This remains a
curated explanatory map, not an exhaustive dependency inventory.

## Browser evidence

All 13 topic connectors were clicked. Their exact Chinese conditions and source
counts match the registry; both endpoints highlight, closing restores focus and
all topic paths remain. Expanding each topic preserves the complete topology and
its geometry. No generic central node remains. Skill branches fold independently
inside the same primary canvas.

All 70 skill selection paths pass exact name/purpose visibility, four Chinese usage
fields, concrete relation counts and neighborhood checks. Search and cross-topic
peer navigation reveal folded destinations. Request retention, keyboard selection,
dismissal/focus, selected-node visibility and context-only resize pass.

Five widths (360, 390, 1024, 1280 and 1440px), each in light and dark, pass label
bounds, compact skill sizing and no document overflow. The checks sample actual
SVG paths against topic and skill interiors, reject proper topic segment crossings
including diagonals, and reject relation-label overlap with topics or each other.
Label clearance passes with the inspector both open and closed. A stale immediate
inspector layout was reproduced and fixed by synchronous topic redraw.

The complete topic board fits the recorded 1280×800 desktop viewport. Desktop
overview and mobile captures were visually inspected. Small screens retain readable
labels using normal vertical scrolling; the report does not claim simultaneous
mobile visibility of the whole graph. These checks do not establish user
comprehension, approval of the draft documents or actual skill execution.
